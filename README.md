# 高原温室生产协同

保存高原温室的种植计划、农技方案和采收批次。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`，领域模型设计见 `docs/domain-model.md`。当前记录类型在温室棚区、作物季次、土壤检测、农技方案、田间操作、采收批次之外，新增作物批次、育苗批次、水肥配方、植保记录、班次计划、采收订单、冷链能力和溯源档案；流程状态为待定植 → 生长中 → 需干预 → 待采收 → 已采收 → 已交付。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

v2 资料新增 `domain_events` 列表，列出会触发后续任务重算的六类扰动：病害发生、设备停机、配方更正、跨棚调苗、延迟采收、冷链能力变化。升级为纯追加变更，v1 消费者可安全忽略新字段。

已整理的业务事实：

- 村庄建设日光节能温室和高山区滴灌工程
- 技术团队会根据土壤差异调整有机肥和生物制剂
- 园区同时组织种植、采摘和冷链运输
- 农技方案需注明适用条件，现场调整需写明观察依据
- 扰动事件发生时受影响的后续任务随之重算
- 离线田间记录联网后仍按真实发生时间落位
- 装箱产品可沿采收批次追溯棚区、投入品、操作人和技术版本

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态、领域事件和事实说明。后续服务应继续兼容这份公开资料约定。
